# SaveFood — демо

Статичная копия главной страницы, витрины и карточки заведения сервиса
SaveFood. Один файл без сборки: Tailwind и MapLibre подключены с CDN, данные
демонстрационные, окна выдачи пересчитываются от текущей даты при открытии
страницы.

Открыть: https://moldir24.github.io/FoodSaver/

Интерфейс и демо-данные переведены на три языка: қазақша, русский и English.
Язык переключается в шапке и запоминается в браузере, при первом заходе
берётся из языка системы.

Навигация внутри страницы — по хэшу:

| Экран | Ссылка |
| --- | --- |
| Главная | `#/` |
| Витрина | `#/explore` (можно с фильтрами: `#/explore?city=almaty&maxPrice=1500`) |
| Заведение | `#/places/coffee-dostyk` |

Регистрация, вход и бронирование не работают — это демо для показа, без
сервера и базы данных.

## Локально

```sh
npx serve .
```
